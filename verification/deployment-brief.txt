ЛОКАЛЬНАЯ ПАПКА

Рабочий проект должен находиться здесь:

│

│   └── ...
│
└── scripts
└── ...

Если CSS и JS находятся внутри index.html, искусственно выносить их в отдельные файлы только ради структуры не требуется.

ПУБЛИКАЦИЯ GITHUB PAGES

Использовать такую же схему, как в остальных статических проектах Евгения.

GitHub Pages:

Branch:
main

Folder:
/ (root)

То есть index.html должен находиться непосредственно в корне репозитория.

НЕ создавать GitHub Actions workflow для простой публикации этого статического сайта.

НЕ нужен файл:

.github/workflows/pages.yml

НЕ нужен deploy.yml.

НЕ нужен другой YAML workflow, если для этого не появляется отдельная техническая необходимость.

В корне проекта создать пустой файл:

.nojekyll

GitHub Pages должен публиковать содержимое main непосредственно из корня репозитория.
